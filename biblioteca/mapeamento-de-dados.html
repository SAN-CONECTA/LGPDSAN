1. Introdução e Contexto

O Mapeamento de Dados é um levantamento detalhado de todos os dados pessoais tratados pelo escritório de contabilidade, suas fontes, fluxos, armazenamento, compartilhamento e destinação final. Este documento atende aos requisitos da Lei Geral de Proteção de Dados Pessoais (LGPD — Lei nº 13.709/2018) e serve como base para auditorias internas, avaliações de conformidade e implementação de medidas de segurança.

Objetivos deste mapeamento:

  • Identificar e catalogar todos os dados pessoais coletados, processados e armazenados

  • Documentar a origem, finalidade e base legal de cada dado

  • Mapear fluxos de coleta, processamento, armazenamento, compartilhamento e eliminação

  • Identificar riscos de segurança e conformidade

  • Definir responsabilidades e papéis na governança de dados

  • Estabelecer prazos de retenção conforme legislação aplicável

  • Gerar insumo para Avaliação de Impacto à Proteção de Dados (AIPD) quando necessário

Escopo: Este mapeamento abrange todas as áreas operacionais do escritório de contabilidade, incluindo contabilidade gerencial, departamento fiscal, departamento pessoal, administrativo, financeiro e relacionamento com clientes.

3. Fluxo de Dados

3.1 Fluxo Geral: Coleta → Processamento → Armazenamento → Compartilhamento → Eliminação

Etapa 1: Coleta

  • Fonte: Cliente (contrato, formulário online, documentação), Titulares (funcionários, sócios), Registros públicos (Receita Federal, Junta Comercial), Sistemas de terceiros (bancos, plataformas fiscais)

  • Método: Presencial (assinatura de contrato), Digital (formulário web), Automático (integração de APIs, sincronização de sistemas)

  • Consentimento: Obtido por escrito no contrato de serviço ou aviso de privacidade para dados não obrigatórios

  • Ponto de Entrada: Email corporativo, portal de cliente, sistema CRM, telefone, contato pessoal

Etapa 2: Processamento

  • Classificação: Dados categorizados por tipo (fiscal, trabalhista, financeiro, pessoal) e nível de sensibilidade (público, confidencial, secreto)

  • Validação: Verificação de completude, formato correto, atualização (ex: CPF válido, CNPJ ativo na Receita)

  • Enriquecimento: Dados complementados com informações de terceiros (ex: endereço atualizado, status de empresa)

  • Normalização: Conversão para formato padrão (ex: datas em DD/MM/AAAA, valores em Real)

  • Análise: Processamento para relatórios, cálculos fiscais, folha de pagamento
