Governança e Políticas LGPD

Guia Completo para Escritório de Contabilidade

Documento de Referência e Implementação

Data de Emissão: 6 de outubro de 2026

Versão: 1.0

1. INTRODUÇÃO E OBJETIVOS

A Lei Geral de Proteção de Dados Pessoais (LGPD — Lei nº 13.709/2018) estabelece diretrizes obrigatórias para o tratamento de dados pessoais no Brasil. Para escritórios de contabilidade, que lidam com informações sensíveis como CPF, CNPJ, dados financeiros, históricos fiscais e informações de sócios e funcionários, a conformidade com a LGPD não é apenas uma recomendação legal, mas uma exigência fundamental.

Este documento apresenta um framework completo de Governança e Políticas adaptado especificamente para escritórios de contabilidade, cobrindo estrutura organizacional, proteção de dados, procedimentos operacionais, treinamento, documentação e resposta a incidentes.

Objetivos deste guia:

  • Estabelecer claramente papéis e responsabilidades na organização

  • Definir políticas de coleta, armazenamento, compartilhamento e eliminação de dados

  • Garantir conformidade contínua com a LGPD e legislação correlata (fiscal, trabalhista)

  • Proteger dados pessoais contra vazamentos e abusos

  • Criar procedimentos padrão para atender direitos dos titulares

  • Documentar decisões e manter auditoria rastreável

  • Preparar a organização para possíveis fiscalizações da ANPD (Autoridade Nacional de Proteção de Dados)

2. ESTRUTURA DE GOVERNANÇA

2.1 Hierarquia e Papéis Definidos

A governança de proteção de dados em um escritório de contabilidade deve seguir uma estrutura clara, com delegação de responsabilidades e níveis de acesso apropriados para cada função.

Papel Responsabilidades Principais Nível de Acesso Reporta a
Controlador de Dados (Sócio/Diretor) Define finalidades do tratamento; autoriza políticas; responde a órgãos reguladores (ANPD); aprova orçamento para conformidade; decide sobre compartilhamentos com terceiros; assina declarações de conformidade Executivo total Conselho/Assembleia (se houver)
DPO (Encarregado de Proteção de Dados) Supervisiona conformidade LGPD; monitora cumprimento de políticas; recebe e investiga reclamações; coordena auditorias internas; notifica à ANPD em caso de incidentes; assessora em novas iniciativas; mantém registro de atividades de tratamento (RRPD) Administrativo total Controlador (direto)
Gestor de Dados / Data Manager Cataloga todos os dados da organização; define e monitora prazos de retenção; autoriza compartilhamentos internos; coordena eliminação segura; mantém inventário atualizado; reporta riscos detectados Gerencial (acesso a metadados e políticas) DPO
Responsável de TI / Segurança da Informação Implementa medidas técnicas de segurança (criptografia, firewall, backup); gerencia autenticação e controle de acesso; registra logs de atividade; responde a incidentes técnicos; realiza testes de penetração; mantém documentação técnica Técnico/Administrativo DPO
Analista / Contador (Operador) Processa dados conforme instruções do controlador; não compartilha dados sem autorização; reporta acessos suspeitos ou incidentes; participa de treinamentos; segue procedimentos de segurança Operacional (acesso restrito a dados necessários para função) Coordenador operacional / DPO
Responsável de RH Garante que contratos de trabalho incluam cláusulas LGPD; coordena revogação de acesso ao desligar funcionário; participa de treinamentos; reporta incidentes envolvendo funcionários Administrativo (acesso a dados de pessoal) DPO
Responsável Jurídico Analisa bases legais para cada tratamento; elabora e revisa contratos com clientes/fornecedores (cláusulas de proteção de dados); prepara respostas a solicitações de direitos; acompanha legislação correlata (fiscal, trabalhista) Administrativo Controlador / DPO

2.2 Comitê de Conformidade LGPD

Propósito: Órgão colegiado responsável por revisar políticas, autorizar novos tratamentos de dados, investigar incidentes e garantir que a organização permaneça em conformidade contínua.

Composição:

  • DPO (presidente do comitê)

  • Controlador ou representante executivo

  • Responsável de TI / Segurança

  • Responsável Jurídico

  • Gestor de Dados

  • Responsável de RH (quando temas trabalhistas forem relevantes)

Frequência de Reuniões: Trimestral, mínimo. Reuniões extraordinárias podem ser convocadas em caso de incidente ou nova iniciativa de negócio que envolva tratamento de dados.

Agenda Padrão:

  • Revisão de conformidade do trimestre anterior

  • Análise de novos pedidos de acesso, retificação, exclusão (direitos dos titulares)

  • Avaliação de incidentes de segurança reportados

  • Aprovação de novas políticas ou alterações

  • Avaliação de riscos em novos projetos

  • Status de treinamentos e auditorias

  • Atualização de legislação correlata

Registro e Atas:

  • Cada reunião deve gerar ata documentada com data, participantes, decisões, responsáveis e prazos

  • Atas devem ser armazenadas em local seguro (acesso restrito a membros do comitê)

  • Atas servem como prova de conformidade durante auditorias

3. POLÍTICA DE PROTEÇÃO DE DADOS

3.1 Princípios Fundadores (Artigo 6º da LGPD)

Toda atividade de tratamento de dados na organização deve estar fundamentada em pelo menos um destes princípios, conforme exigido pela Lei 13.709/2018:

Princípio Significado Aplicação em Escritório de Contabilidade
Legalidade Todo tratamento de dados deve ter amparo legal (lei, contrato, consentimento informado ou outra base legal válida) Dados de clientes são tratados por contrato de serviço. Dados fiscais, por obrigação legal. Marketing, por consentimento.
Finalidade Dados coletados para uma finalidade específica não podem ser reutilizados para fim diferente sem nova base legal CPF coletado para declaração fiscal não pode ser usado para marketing sem consentimento adicional.
Adequação Dados coletados devem ser apropriados e pertinentes à finalidade declarada Não coletar data de nascimento de cliente se informação não é necessária para prestar serviço contábil.
Necessidade Dados coletados devem ser limitados ao que é necessário; sem excesso Para receber relatório mensal, precisa de email. Não precisa de telefone residencial ou endereço pessoal se comunicação é digital.
Livre Acesso Titulares devem poder acessar, consultar e atualizar dados de forma facilitada Disponibilizar portal de autoatendimento ou responder em até 20 dias a pedidos de acesso.
Qualidade Dados devem ser corretos, completos, precisos e mantidos atualizados Implementar procedimento de revisão periódica de endereços, telefones, emails. Corrigir dados inexatos ou desatualizados.
Transparência Titular deve ser informado de forma clara e compreensível sobre coleta, uso e compartilhamento de seus dados Fornecer Aviso de Privacidade claro, em linguagem simples, explicando como dados serão usados.
Segurança Dados devem ser protegidos contra acesso não autorizado, vazamento, alteração ou destruição Implementar criptografia, firewall, controle de acesso, backup seguro.
Responsabilização Organização deve manter registros demonstrando que está em conformidade (accountability) Manter RRPD atualizado, registrar consentimentos, documentar decisões do Comitê.

3.2 Bases Legais para Tratamento de Dados

A LGPD (Art. 7º) define as bases legais que legitimam o tratamento de dados pessoais. Cada tipo de dado coletado deve estar vinculado a pelo menos uma base legal.

Base Legal Definição Exemplos em Contabilidade Requisitos
I — Consentimento Titular concorda, de forma informada e explícita, com o tratamento Marketing por email; cookies de rastreamento; pesquisa de satisfação Consentimento deve ser: obtido antes do tratamento; informado (transparente); específico (não genérico); livre (sem coação); revogável
II — Contrato Tratamento é necessário para executar contrato ou relação pré-contratual Dados de cliente para prestar serviço contábil; dados para enviar notas fiscais; dados para processar pagamento Dado deve ser essencial para a relação contratual. Se não fornecer, cliente não recebe serviço.
III — Obrigação Legal Lei, norma ou regulação exige o tratamento Dados fiscais (5 anos); dados trabalhistas (conforme CLT); dados para compliance com fisco, receita, auditoria Deve haver cita legal ou normativa. Prazo de retenção é definido por lei.
IV — Tutela de Vida Tratamento é necessário para proteger vida ou saúde (rara em contabilidade) Informações de emergência de funcionários (contato de parente próximo) Aplicável apenas quando vida está em risco.
V — Exercício de Direito Dados são tratados para defender direito em juízo ou processo administrativo Documentos para defesa em auditoria fiscal; evidência em disputa com cliente Aplicável apenas para fins de defesa legal.
